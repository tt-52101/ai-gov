# Project Rules

## 入口
完整的项目规则和领域上下文见 `.trae/rules/context.md`。

## 核心铁律（不可违背）
1. Token = AI 时代的电力；无计量则无管理；无归因则无法优化
2. 无企业自有调用入口则无法真正掌控 AI 资产与成本
3. 无守恒账本则无财务治理护城河
4. 调度不得改变扣费账户；内部结算价格受请求锚定与上浮上限约束；禁止先调用后欠费
5. 数据范围、资金、身份密钥、调度与模型配置四轴正交授权；禁止一轴推导另一轴特权
6. 平台管理员也必须经账本服务与流水变更余额，不得提供绕过守恒的后门接口
7. 财务治理闭环是第一护城河（双轨计价、主体账本、划拨清算、Key 扣费、预算帽分码、守恒流水）

## 能力优先级
- P0: 统一接入与密钥托管 | 财务治理与计量闭环 | 正交授权/数据不越权/模型访问治理 | 调度与资金强制边界 | 治理 API 与资金写幂等
- P1: 可插拔路由策略矩阵与降本高可用 | 基础运营报表与仪表盘
- P2: 内容安全与出网强化 | 配置变更快照强化、上游账单自动对账
