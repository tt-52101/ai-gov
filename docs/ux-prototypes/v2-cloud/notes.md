## 1. 设计意图（Why）

### 1.1 目标

为 Guardian Gateway v3.2.1 企业 AI 网关治理后台设计一套**企业云风格**原型，与 v1（政务风）、v3（其他风）形成三套对比，用于产品/设计/技术三方在 W1 选型会上一锤定音。

### 1.2 风格定位

| 维度 | 选型 | 理由 |
|------|------|------|
| **基线** | 华为云 / 腾讯云企业级控制台 | "可托付"是金融/政企客户首要心理诉求 |
| **主色** | 华为青 #0066FF | 不刺眼、不幼稚、专业感强、与"电力=基础设施"隐喻匹配 |
| **暗色** | 深空蓝 #0A2540 | Stripe / Vercel / 华为云 Hero 通用底色，营造"可托付" |
| **密度** | 高 | 政企后台使用者多为 IT/运维/财务专业人员，习惯高密度表格 |
| **数据可视化** | recharts 风格静态 SVG | 与生产代码栈保持一致，便于后续 1:1 落地 |

### 1.3 风格 DNA 一句话

> **深空蓝打底 + 华为青点睛 + 信息密度高 + 状态灯清晰 + 数据大字号 + 银行级可托付**

### 3.2 字体栈

```
"HarmonyOS Sans", "PingFang SC", "Microsoft YaHei", "Inter", -apple-system, BlinkMacSystemFont, sans-serif
```


**字距优化**：所有 KPI 数字使用 `font-variant-numeric: tabular-nums`，避免小数位宽度抖动。

| 8 | 32px | section 之间 |
| 12 | 48px | Hero 区域顶部 |
| 16 | 64px | 极端留白（暂未使用） |

### 4.2 圆角（紧凑 6px / 4px 混合）

| 角色 | 圆角 | Tailwind | 场景 |
|------|------|----------|------|
| **主圆角** | 6px | `rounded-md` | 卡片、按钮、徽标 |

## 5. 6 页面详细说明

### 5.1 ① Dashboard

**核心要素**：

- **深色 Hero 头部** `#0A2540` + 32px 网格背景 + Logo + 顶部导航条 + Hero 主体
- **4 个 KPI 大数字 48px**：总调用量 / 总消耗 / 成功率 / 活跃 Key
  - 每个 KPI 配 sparkline 小折线图
  - 涨跌用 `#10B981` 绿 / `#F59E0B` 橙 区分
- **主图表区**：纯 SVG 折线图，含图例、Y/X 轴、数据点高亮、渐变面积
- **实时事件流**：左侧 2/3 主图，右侧 1/3 Live 事件，每条带状态灯 + 时间戳 + 哈希 ID

**信息密度**：6 个元素一屏，单屏可视信息量比 v1 提升约 40%。

### 5.2 ② Sidebar v1（紧凑版）

**核心要素**：

- 240px 宽
- 一级 12px / 二级 12px（同字号，颜色区分）
- 一级菜单 h-8（32px）/ 二级菜单 h-7（28px）
- 选中态：浅蓝底 `#EFF6FF` + 文字 `#0066FF` + 500 字重
- 底部固定用户区

**与 v1（政务风）对比**：v1 圆角 8px，间距宽；v2 圆角 6px，间距紧凑。

### 5.3 ③ Sidebar v2（升级版）

**核心要素**：

- 256px 宽（比 v1 多 16px）
- 一级 14px / 二级 12px（**关键差异：拉开字号差**）
- 一级菜单 h-10（40px）/ 二级菜单 h-8（32px）
- **关键差异**：选中态使用 **3px 青蓝左边框**（`::before` 伪元素）+ 浅蓝底 `#F0F7FF` + 600 字重
- 二级菜单选中后跟随父级高亮（视觉血脉）
- 顶部新增**工作区切换**（生产/测试/开发）
- 一级菜单内可放状态徽标（数字、状态灯）

**核心突破**：用 3px 左色条 + 字重提升 + 字号差，形成"三层视觉锚点"（左色条 / 字号 / 字重），即便色弱用户也能识别选中。

### 5.4 ④ 资金管理

**核心要素**：

- **深色余额面板**：`bg-gradient-to-br from-[#0A2540] to-[#14365E]` + 网格背景
- **超大余额数字 56px**（银行风关键）
- 旁边 3 个辅助卡片：今日消耗 32px / 本月毛利 32px
- 守恒校验状态灯（绿色）
- 下方：流水表格 + 子账户列表
- 流水表 7 列：时间 / 类型 / 主体 / 金额 / 方向 / 余额 / 流水号
- 金额用 `font-mono` 等宽，方向用色块标识（debit 红 / credit 绿 / transfer 蓝 / unfreeze 绿）

**银行风体现**：
1. 守恒校验状态明确显示
2. 流水表按时间倒序
3. Idempotency-Key / tx-id / freeze-id 等哈希字段显眼
4. 金额数字使用 tabular-nums 对齐

### 5.5 ⑤ 模型列表

**核心要素**：

- 紧凑表格 11 列
- 顶部操作栏：搜索 / 筛选 / 接入新模型
- 表头：`text-[11px] uppercase tracking-wider`（英文风格 small caps，参考 GitHub / GitLab）
- 每行：模型 Logo 色块（供应商品牌色）+ 模型名 + 版本 + 供应商徽标 + 类型 + 上下文 + 输入价 / 输出价 + 健康度 + P99 + 状态
- 状态指示灯：绿/黄/红/灰
- 降级模型：mistral-large-2 用红色（95.10% 健康度 + 312ms）
- 停用模型：stable-diffusion-3 整行变灰 + 状态灯灰
- 底部：分页器

**信息密度提升**：在 1440px 宽度下展示 11 列 + 7 行数据，每行 36px 高，比 v1 增加 60% 信息量。

### 5.6 ⑥ 操作审计

**核心要素**：

- 左侧 1/3：严重度分布（4 条带数据百分比横条）+ 筛选（操作类型/操作人/时间范围）
- 右侧 2/3：**深色时间线面板** `#0A2540` + 网格背景
- 时间线：左侧 1px 竖线（白色 15% 透明）+ 节点圆点（带 box-shadow 双层环）
- 每条事件：**严重度色块**（左 3px 色条 + 浅色背景）+ 等级徽标 + 事件名 + 详细描述 + trace/req/actor 元数据
- 4 种严重度：严重（红）/ 警告（橙）/ 信息（蓝）/ 成功（绿）

**政务风体现**：
1. 时间线（来自阿里云 ActionTrail）
2. 严重度等级明确（政务/审计刚需）
3. 不可篡改声明（SHA-256 链式哈希）
4. 保留期标注（180 天）

## 7. 实现细节

### 7.1 严格遵守的约束

- ✅ 仅用 TailwindCSS CDN，无其他依赖
- ✅ 无 JavaScript（图表用纯 SVG 模拟，菜单用 CSS-only）
- ✅ 不改 `src/` 下任何代码
- ✅ 不改 `globals.css` 或 token
- ✅ 注释全部中文
- ✅ 浏览器直接打开 `index.html` 可见

### 7.2 关键技术点

- **Tailwind arbitrary values**：`bg-[#0A2540]` / `text-[48px]` / `pl-12` 等自由组合
- **伪元素左边框**：`nav-active::before` 实现 3px 选中色条
- **CSS-only hover**：`.nav-1:hover` / `.nav-2:hover`
- **SVG 折线图**：纯静态 path + 渐变 fill + 数据点
- **等宽数字**：`font-variant-numeric: tabular-nums` 防抖动
- **滚动条美化**：`::-webkit-scrollbar` 深色/浅色双套

### 7.3 浏览器兼容

- Chrome / Edge ≥ 90 ✅
- Firefox ≥ 88 ✅
- Safari ≥ 14 ✅
- 最小宽度 1280px（政企后台默认）
