# 银行级原型 v3-bank · 设计说明

| 项 | 值 |
| --- | --- |
| 文件 | `index.html` (单文件聚合) |
| 风格基线 | 工行/招行/建行网银 (银行级安全风) |
| 设计主色 | 招行红 `#E60012` · 银行深蓝 `#1A365D` |
| 字体 | 思源宋体 / 苹方 / 等宽 JetBrains Mono |
| 圆角 | 4px (主) / 2px (表格) |
| 留白 | 4 倍数体系 (4/8/12/16/24/32) |
| 依赖 | 仅 TailwindCSS CDN · 无 JavaScript |
| 渲染验证 | Chrome/Edge 直接打开即可 |

---

## 一、设计目标 (为什么是银行风)

1. **守恒即资金** — 资金页所有金额数字必须一眼可读,任何差异必须高对比红色警示。
2. **证书感 = 可信** — 审计、Key 守恒校验需要严肃字体 + 边框仪式感,不能"活泼"。
3. **保守 = 抗误操作** — 大圆角、彩色块、emoji 风格在银行场景会让用户怀疑是"假银行"。
4. **高对比 = 防疲劳** — 财务治理组 8 小时盯盘,深色文字 + 浅色底优于炫彩风。

## 三、字号体系 (Font Scale)

| 用途 | 字号 | 字重 | 字体族 |
| --- | --- | --- | --- |
| 页面 H1 | 24px | 700 | 思源宋体 (serif-strict) |
| 卡片标题 | 16px | 600 | 苹方 |
| 正文 | 14px | 400 | 苹方 |
| 辅助说明 | 12px | 400 | 苹方 |
| 表头 | 12px | 600 | 苹方 |
| 标签 / 徽标 | 11-12px | 500 | 苹方 |
| **KPI 大数字** | **32-48px** | **700** | **等宽 (tabular-nums)** |
| **金额大数字** | **48px** | **700** | **等宽** |
| 流水小数字 | 12-14px | 400 | 等宽 |

**关键规则:** 所有数字必须用等宽字体 + `font-variant-numeric: tabular-nums`,保证对齐;金额字段必须用大字号 + 加粗 + 等宽 + 字距 -0.04em。

## 四、留白 (Spacing)

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 4px | 紧凑行内 |
| `space-2` | 8px | 列表项内 |
| `space-3` | 12px | 卡片内边距 (紧凑) |
| `space-4` | 16px | 卡片内边距 (标准) |
| `space-6` | 24px | 大区块内边距 |
| `space-8` | 32px | 区块间距 |

> 留白节奏 4 倍数,避免 5/7/9 等杂值。银行卡片用 16-20px,KPI 卡片用 20px,审计区段用 20-24px。

---

## 五、圆角 (Radius)

| Token | 值 | 用途 |
| --- | --- | --- |
| 主圆角 | 4px | 卡片 / 按钮 / 徽标 |
| 表格圆角 | 2px | 表格 / 表头 (更紧凑更"银行") |
| 极小 | 1-2px | Logo / 状态点 |

> 银行场景禁大圆角 (>8px),否则会显得"娱乐化"。v3-bank 全局强制 4px 主、2px 辅。

## 六、6 个 Demo 详解

### Demo 01 · Dashboard 保守稳重视觉
- **核心:** 4 KPI + 资金流趋势 + 守恒概览
- **特色:** 守恒差异 KPI 单独用红色 2px 边框 + 大红字,即使 0.00 也保持视觉张力
- **趋势图:** 纯 CSS 网格 + SVG 折线,内部结算 (深蓝) 与上游成本 (招行红) 双轨对比
- **关键数字:** 32px 等宽 + 字距 -0.04em

### Demo 02 · Sidebar 深色稳重 + 红色 Logo 强调
- **核心:** 深空蓝 (`#0A1B30`) 底色 + 招行红 Logo
- **菜单分组:** 概览 / 资金治理 / 接入 / 安全 四大组
- **选中态:** 红色 15% 透明背景 + 左侧 2px 红色边
- **底部用户:** 红色头像方块 (与 Logo 配色一致,形成"守护"主题)
- **适用:** 政企用户 / 长时间盯盘 / 暗光环境

### Demo 03 · Sidebar 升级版 (高对比 + 14px + 4px 圆角)
- **核心:** 浅色底 + 14px 统一字号 + 4px 圆角
- **选中态:** 深蓝实底白字 (与深色版形成"A/B 测试"对照)
- **对比表:** 列出与 DEMO 02 的差异 (字号/圆角/选中态)
- **适用:** 浅色偏好 / 白天办公 / 打印场景

### Demo 04 · Account 资金管理
- **核心:** 守恒红色 banner + 48px 金额大数字 + 流水表格
- **守恒 banner:** 渐变红底 + 4px 左侧色块 + 惊叹号图标 + 校验元数据
- **主账户卡:** 48px kpi-number 金额 + 4 个子指标 (可用/冻结/预算帽/冻结率)
- **流水表:** 5 条样例 (划拨/结算/冻结/划拨/结算),状态徽标 + 严重度色彩
- **子账户列表:** 财务治理组余额用招行红显示 (警示:余额过低)

### Demo 05 · Model 模型列表
- **核心:** 紧凑表格 + 2px 圆角 + 价格列等宽对齐
- **字段:** 模型 ID / 名称 / 厂商 / 输入价 / 输出价 / 状态 / ModelGrant
- **状态徽标:** 运行中 (绿) / 降级中 (黄) / 已停用 (红)
- **ModelGrant:** allow (蓝) / deny (红)
- **底纹:** 降级中行用 amber 底纹,已停用行用 red 底纹
- **分页:** 简洁的 1/2 页切换

### Demo 06 · Audit 操作审计
- **核心:** 左侧筛选 + 右侧时间线 + 严重度色彩 + 思源宋体
- **时间线:** 红蓝渐变竖轨,圆点带 4px 环
- **严重度:** 高 (招行红) / 中 (琥珀) / 低 (蓝) / 信息 (灰)
- **证书边框:** 顶部 1px 内嵌红色阴影线,模拟"审计卷宗"视觉
- **元数据:** request_id / idempotency_key / key_id / 账户 ID 全部等宽
- **错误码:** `INSUFFICIENT_BALANCE` 用等宽 + 红底高亮 (错误码字面量必须显式可见)

## 八、不做什么 (Negatives)

- ❌ 不引入大圆角 (>8px) — 银行场景会显得"娱乐"
- ❌ 不使用 emoji — 用方块符号/几何图形代替
- ❌ 不使用渐变背景 — 仅守恒 banner 允许极轻渐变
- ❌ 不使用彩色阴影 — 仅边框 + 1px 阴影
- ❌ 不使用插画 — 银行风必须是"证书感",插画会破坏仪式感
- ❌ 不使用动画 / 过渡 — 静态呈现,对比清晰

---

## 九、可访问性 (A11y)

- 文字对比度均 ≥ 4.5:1 (WCAG AA)
- 招行红 `#E60012` 在白底对比度 5.4:1
- 银行深蓝 `#1A365D` 在白底对比度 11.2:1
- 严重度徽标不仅用颜色,还配文字标签 (高/中/低/信息)
- 所有金额数字配语义化的字号层级 (h1/h2/h3)
