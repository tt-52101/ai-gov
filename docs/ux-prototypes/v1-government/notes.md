# Guardian Gateway v3.2.1 · 政企风原型 v1 设计说明 | 版本：v1.0 | 日期：2026-08-03 | 状态：评审中

> 本文档为政企风原型 demo 的设计说明，用于浏览器内对比选型。所有视觉决策均基于《2026-08-03-ux-redesign-design.md》第 1-10 节 Design Token 体系。

---

## 一、设计目标

提供 1 套**政企风原型 demo**，在浏览器内直接对比 6 个关键页面的视觉方案，对照 v3.2.1 baseline 暴露的"密集反人类菜单"等问题，验证融合方案（阿里 Ant Design Pro 政务 + 银行级安全 + 华为企业云）的可落地性。

**核心诉求：**
- 严肃 / 规整 / 纸面感 — 政务权威性
- 红色守恒提醒 — 银行级安全
- 高信息密度 + 卡片化 — 华为企业云
- 中文文案 + 中文注释 — 不可妥协的本地化

## 三、字号体系（Type Scale）

采用 1.25 黄金比例，8 级字号体系：

| Token | 像素 | 用途 |
|-------|-----|------|
| `text-xs` | 12px / 16px | 辅助说明、表格内文 |
| `text-sm` | 14px / 20px | 一级菜单、表头、正文 |
| `text-base` | 16px / 24px | 页面正文 |
| `text-lg` | 20px / 28px | 小标题、卡片标题 |
| `text-xl` | 24px / 32px | 区块标题 |
| `text-2xl` | 32px / 40px | 页面 H1、KPI 大数字 |
| `text-3xl` | 48px / 56px | Hero 大标题 |

**Sidebar 层次决策：**
- 一级菜单：**14px / 600 字重 / 高度 40px**（从 12px 提升 16.7%）
- 二级菜单：**13px / 400 字重 / 高度 32px**（从 12px 提升 8.3%）
- 选中态：政务蓝左 3px 边 + `gov-50` 浅蓝底

## 四、留白与圆角

| 维度 | 体系 | 取值 |
|------|------|------|
| **留白** | 8 倍数 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| **圆角** | 8 倍数 | 4 (辅) / 8 (主) / 12 (lg) / 16 (xl) |
| **阴影** | 4 级 | sm / card / card-hover / gov |

**主圆角：`rounded-lg` (8px)** — 用于所有卡片、按钮、徽标。  
**辅圆角：`rounded` (4px)** — 用于表格内徽标、chip。  
**无圆角：** 表格、表头分隔线、严格规整的政务风元素保留直角。

## 五、6 个 Demo 页面设计要点

### ① Dashboard — 治理总览

- **顶部 4 KPI**：可用余额、今日调用、路由命中率、守恒告警 — 大数字 `text-2xl` + sparkline 趋势
- **第 4 个 KPI 银行红边**：守恒告警用 `bank-500` 左 4px 边，视觉锚点
- **中部双图区**：调用量趋势（蓝色实线 + 填充）+ 成本趋势（红色虚线） — 纯 SVG，无 JS
- **实时事件流**：6 条 mock 事件，涵盖 5 种语义色（守恒/划拨/结算/预算/路由/授权）
- **9 宫格入口**：组织/资金/Key/模型/治理 ABAC/治理 PBAC/审计/报表/设置

### ② Sidebar 原版（反人类样态）

- 故意保留 12px 小字号 + 8 个平铺子菜单 + 无层次
- 配合右侧"问题诊断"红色横幅 + 三组反例数据（12px / 8 个 / 400字重）
- **目的**：直观对比反例，避免被新版掩盖问题严重性

### ③ Sidebar 升级版

- 14px / 600 一级 + 13px / 400 二级
- 政务蓝深色 header 强化品牌
- 选中态：左 3px 蓝边 + 浅蓝底 + 加粗
- 治理分类合并 ABAC/PBAC 为单一父级
- 系统设置折叠（▸ 角标）
- 右侧绿色"设计要点"横幅 + 三组正向数据

### ④ Account 资金管理

- **守恒横幅**（强制视觉锚点）：银行红 4px 左边 + `bank-50` 渐变底 + "权威合规"徽标 + "立即核查"按钮
- **守恒四联卡**：Σ余额 / Σ冻结 / Σ在途 / 守恒校验 Δ
- **账户列表**：6 行示例，包含 1 行异常（红色）、1 行预算告警（黄色）、4 行守恒（绿色）
- 操作列"详情 / 流水"双链接

### ⑤ Model 模型列表

- **筛选条**：供应商 + 能力 + 状态 三组 chip + 搜索框
- **卡片网格 4 列**：8 张卡片，覆盖 4 种状态（启用/降级/停用/试用）
- 每卡片含：Logo（首字）、供应商、上下文、输入/输出价、P99 延迟、今日调用、能力 chip
- **第 8 张"添加新模型"**：虚线边框 + 渐变 + 居中 `+` 图标 — 体现空状态/CTA

### ⑥ Audit 操作审计

- **严重度分布** 5 卡：严重/高/中/低/合规率 — 用四级色
- **时间线主体**：左侧 2px 灰线 + 事件点 ring 高亮
- 6 条 mock 事件：守恒异常（严重红）/ Key 撤销（高橙）/ 划拨执行（中蓝）/ 策略变更（中蓝）/ 登录（低灰）/ 模型授权（低灰）
- 每事件含：audit ID / 描述 / 触发人 / IP / 时间
- 分页器：1/2/3/…/37

## 七、技术约束遵守

- [x] **不引入新依赖** — 仅 TailwindCSS CDN（`cdn.tailwindcss.com`），通过 `tailwind.config` 内联扩展
- [x] **不改 src/ 下任何代码** — 输出仅在 `docs/ux-prototypes/v1-government/`
- [x] **不改 globals.css 或 token** — 原 token 体系保持，本原型仅复用语义
- [x] **不写 JavaScript** — 纯 HTML + TailwindCSS，图表用内联 SVG 模拟
- [x] **中文文案 + 中文注释** — 全部 HTML 注释为中文
- [x] **锚点导航** — `#dashboard` `#sidebar-old` `#sidebar-new` `#account` `#model` `#audit` 全部可达
